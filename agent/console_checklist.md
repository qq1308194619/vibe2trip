# 百炼 Managed Agent 控制台复刻清单（约 10 分钟，全部复制粘贴）

> 目的：让评委/使用者在百炼控制台从零复现作品主形态。真实 Key 一律通过"会话环境变量"注入，**绝不写进任何提交文件或聊天记录**。
> 本清单对应的真跑关键帧截图已存于 `assets/shots/agent_03~06_*.png`。

## 1. 进入 Managed Agent
- 打开 https://bailian.console.aliyun.com → 应用/智能体 → **Managed Agent（Agent Studio）**。

## 2. 创建智能体
- 名称：`Vibe2Trip · 旅行审美解构师`
- 模型：选**支持图片输入的多模态模型**（Qwen3.8-Max 原生多模态可直接读图；若列表用别名则选任一 Qwen-VL / qwen3-vl 系列，能收 image 输入即可）。
- 系统提示词：整段粘贴 `agent/managed_agent_system_prompt.md` 正文（从"你是 Vibe2Trip…"到结尾）。
- 其余默认，保存。

## 3. 新会话安装飞猪 Skill
在会话输入框发送，等它执行完并回复安装成功：
```
npx skills add alibaba-flyai/flyai-skill
```

## 4. 注入飞猪 Key（会话环境变量）
- 在该会话的「环境变量」里加一行：`FLYAI_API_KEY = <你自己的飞猪 Key>`。
- 入口：https://flyai.open.fliggy.com/console 申请。不配则走飞猪**体验模式**，商品/链接真实但价格被掩码（见第 7 节）。

## 5. 挂载灵感图并测试
- 会话「文件」上传 `assets/demo_inspiration.png`（仓库自带，原创生成、无版权风险），确认它被挂载到 `/uploads/`。
- 发送：
  ```
  请用 read 读取 /uploads/demo_inspiration.png，按系统提示词输出：审美画像 7 维 → 命定目的地（城市级）→ flyai 真实数据 → 排满每天 → 心动旅行卡。
  上海出发，2 人情侣，中等预算，2026-11-08 起 3 天。
  ```
- 预期链路（逐段核对）：
  1. 7 维审美画像 + 一句话心动理由 + `recognized_place`（认不出如实写"图中未体现"）；
  2. 命定目的地为城市级（如 苏州/嘉兴），标首选 + 候选命中维度；
  3. flyai 真实返回：景点带详情链接、住宿带真实单价、无机场城市对自动回退高铁；
  4. 每天×上午/下午/晚上排满，每个景点带 `vibe_tag`；
  5. 心动旅行卡 ①~⑥ 齐全，预算口径写清（交通按人、住宿按房分摊）。
- **（条件出现，非必查）** 若命中下列场景，卡片会多出 ⑦「心动对价 · 拍摄窗口 · 季节提示」；没命中就没有这一段，**属正常，不是缺功能**：
  - 预算/天数与心动成本错配 → 给「审美平替」并写明哪一维让步；
  - 心动主体当季不存在 → 给「季节时差」+ 同款情绪替代；
  - 图中氛围有可量化的现实代价（如"夜里无人的水道"≈入住景区内部）→ 用真实差价摊开。
- 想加演**跨媒介泛化**：换一张动漫/游戏场景截图，核对它仍被解构成 7 维，且取景地推测带「疑似取景地（二次元推测，未核实）」标注。
- 想加演**同行结构投影**：同一张图把「2 人情侣」改成「2 大 1 小，孩子 5 岁」重发，核对画像 7 维不变、但住宿/节奏/活动确实重排。

## 7. 常见故障
- `npx skills add` 失败：新开会话重试一次；仍失败去大赛交流群 @管理员。
- 模型列表无多模态模型：换任一 Qwen-VL / qwen3-vl 系列；关键是能接受图片输入。
- 价格显示 `¥1x` / `¥6x`：是飞猪**体验模式**掩码（未配正式 Key 或额度用尽），属预期；卡片会如实标注且掩码项不计入预算。用正式 `FLYAI_API_KEY` 可解真实价格。
- flyai 命令结束时偶发 `UV_HANDLE_CLOSING` 断言：Windows 下无害的进程 teardown 噪音，stdout 的 JSON 已完整，以 JSON 为准。
