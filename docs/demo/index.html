新会话里装飞猪技能，并注入 Key

在会话输入框发这句，等它回复安装成功（云沙箱内执行，官方 skill 自己做逐请求签名）：

npx skills add alibaba-flyai/flyai-skill

然后在该会话的「环境变量」里加一行 FLYAI_API_KEY（申请入口 flyai.open.fliggy.com/console）。

⚠️ 两个坑，都是真踩出来的：① Key 要配在会话级环境变量，只配在智能体上可能不生效，未生效时 flyai 会静默回落到公共体验 Key且不报错（表现为价格变成 ¥1xx 掩码）；② 别用百炼「密钥库」注入——它会替换 Authorization 头，而 flyai 对该头签名，替换后 401。
