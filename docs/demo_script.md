# 演示脚本（视频/截图分镜）

> 目标：2~3 分钟让评委看清「一张心动的图 → 审美解构 → 真实可预订行程」的完整闭环，突出唯一差异化：审美解构。
> 建议：录屏 + 关键帧截图存入 assets/，视频 60~120 秒，配字幕。

## 分镜

**镜头 0 · 开场（5s）**
- 画面：作品名「Vibe2Trip · 这张图的感觉，帮我安排」+ 一句话价值。
- 字幕：不知道去哪？但你已经存了那张心动的图。

**镜头 1 · 上传灵感图（15s）**
- 操作：在百炼智能体会话里上传一张有辨识度的灵感图（建议：一张暖调湖景/海边度假/雪山/古镇夜景，或一帧电影剧照、一条小红书截图）。
- 字幕：入口不是打字，是一张图。

**镜头 2 · 审美解构（30s）——重点戏**
- 画面：Agent 输出「旅行审美画像」7 维（地貌/色调/氛围/活动/节奏/季节/人文自然比）+ 心动理由。
- 看点：把感性的一张图，拆成可执行的旅行维度；认不出具体地点时给"神似候选目的地"并逐维说明匹配。
- 字幕：从"这种感觉"到"可执行的审美画像"。

**镜头 3 · 一次问全约束（10s）**
- 操作：Agent 一条消息问全 出发地/日期天数/同行/预算；用户简短回答（或"你看着安排"）。

**镜头 4 · 调飞猪真实数据（25s）**
- 操作：Agent 调用 `/flyai search-poi`、`search-hotel`、`search-flight`（屏幕能看到工具调用与真实返回）。
- 看点：返回的是**真实、带预订入口**的机票/酒店/景点；选择逻辑对应审美画像（如"暖调治愈→湖景高分度假酒店"）。
- 字幕：实时直连飞猪官方库存，可预订、不编造。

**镜头 5 · 心动旅行卡（30s）**
- 操作：展示最终卡片：① 心动解读 ② 命定目的地 ③ 按天行程 ④ 可预订清单 + 总预算区间。
- 看点：每个行程项标注"对应你要的哪种感觉"，每条都能下单。
- 字幕：你已经心动过那张图，我帮你把它变成可以出发的行程。

**镜头 6 · 微调（可选，10s）**
- 操作：用户说"再松弛一点/多些人文" → Agent 调整审美画像重新检索重排。

**镜头 7 · 收尾（10s）**
- 画面：技术栈（百炼智能体 + flyai skill + Qwen-VL）+ GitHub 仓库链接/二维码。

## 演示用图建议
- 选一张审美维度丰富、Agent 能明确读出调性的图，避免过于抽象或信息量太低。
- 优先用自己拍的照片或无版权图，规避侵权（报名须知明确要求原创/合法授权，勿直接用他人小红书原图做商业展示）。
- 备 2~3 张不同调性的图（自然/都市/古镇），演示"同一套审美解构能适配多种感觉"。
