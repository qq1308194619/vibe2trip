## ① 心动解读 · 旅行审美画像

| 维度 | 解构 |
|---|---|
| **地貌场景** | 江南平原水乡：一条不宽的内河，石拱单孔桥（桥洞与倒影合成正圆），右岸连绵白墙黛瓦的临水民居，左岸垂柳压到水面，远景有低矮丘陵轮廓。 |
| **色调光线** | 日落前后低角度暖光：整幅偏琥珀金 + 墨绿，天空近白、水面反光成一条金带；右侧民居**窗内已亮灯**（暖黄小方格），属典型"蓝调前 20 分钟"的逆光剪影。 |
| **氛围情绪** | 安静、私密、无交流的亲密——两人同坐一船背对镜头，不摆拍；"共处而不说话"的安全感。 |
| **活动暗示** | 手摇橹木船（无动力、无顶棚的乌篷/摇橹船）、临水散步、看人家点灯；**没有任何商业娱乐元素**。 |
| **节奏快慢** | 极慢。全画面只有一个移动体，且背向观者远去。 |
| **季节感** | 柳叶仍绿下垂、右下水域有成片残荷 → **深秋将尽**，衣着为深色厚外套。 |
| **人文自然比重** | 人文 7 : 自然 3（建筑、桥、船、窗灯占主体，山水为衬） |

- **heart_reason**：你想存下的不是"一个古镇"，是"和一个人一起、在一条慢慢走的水上、什么都不用说"——窗里亮着的灯替你说了。
- **recognized_place**：**图中未体现**（画面无文字标识、无唯一性地标；桥型+马头墙+水口格局符合江南/徽州一带，但不足以确指，不猜）。

**关键取舍说明**：图中"远景低丘 + 马头墙 + 残荷"的组合，与**皖南徽州**（黄山黟县）的吻合度高于典型苏杭水乡；而"两人一船、窗灯、黄昏"是可完全复现的现实要素。本卡按**真实数据最强、成本最贴合中等预算**的方案落地。

## ⑦ 心动对价 · 拍摄窗口 · 季节提示

### 这份感觉的代价（真实数字）

1. **"夜里无人的水面"要求你住在景区内部。**
   同一次查询里，**景区内+南湖边**的宏村沁春茗苑 ¥237/间/晚；景区外围的游客中心店如家·neo ¥266、全季 ¥351（另有一条"景区内"地址的宏村树人堂雅静·徽式庭院民宿，flyai 未返回其房价，故不参与比价）。差价 ¥29–114/晚看似不大，但它买的是**闭园清场后那 1 小时的空村**——图里"整条河只有你一条船"的现实形态只能出现在人群散去之后。住外面 = 每天随最后一批游客一起被推出湖边。
2. **"整条河只有一条船"在旺季周末概率很低。**
   我把第 2 天排在 **11-09 周一**、塔川放在上午，正是为此；若你只能周末走，请默认接受画桥一带的人流，这一维会明显让步。
3. **"便宜又安静"往往意味着通勤更远。**
   ¥96 的七月七日晴在宏村后街（村内但非湖边），省 ¥141/晚，代价是每晚要走回湖边、且错过清晨推窗见水的那一幕。

### 拍摄窗口（通用光线规律，不含具体时刻）

- **南湖 / 画桥**：**日落前约 30 分钟**是图里那条"水面金带 + 白墙打亮 + 窗内已亮灯"三重条件同时成立的唯一窗口；日落后 15 分钟内窗灯与天光比最接近图。请按 11 月 8 日黟县日落时间**自行核对并提前 40 分钟到位**。
- **塔川**：清晨易有贴地薄雾，逆光穿过乌桕叶才有"通透"感；上午 9 点前到位。
- **宏村村口红白古树**：天光初开时村口无人，是全程最安静的一段；第 3 天退房前那 1 小时就是为此排的。
- ⚠️ flyai **不返回日出日落时刻**，以上只给"提前到位"的相对建议，具体时刻请用当日天气/天文数据核对。

### 季节时差

- 图的**季节感（深秋：残荷 + 厚外套 + 仍绿但下垂的柳）与你 11-08 的出行日期同季**，这是本次映射最顺的一点——不需要平替、不需要迁就。
- **塔川红叶有明显季节窗口**，11 月上旬通常是最佳段，但**具体物候以当年气温为准**，存在提前落叶或延后的可能。若你更在意"满树红"，请把这一项视为概率事件而非承诺；届时若已谢幕，同日可兑现同款情绪的是**晨雾 + 枯荷 + 空村**，而非红叶。
